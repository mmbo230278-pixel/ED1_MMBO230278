## Descripción

Proyecto de la evidencia ED1, que incluye dos sitios web con formularios validados mediante JavaScript:

- **Website de tecnologías:** 4 párrafos, logotipos SVG y formulario con validaciones en cada campo.
- **Website de café:** cada página con un patrón de diseño y formulario con validaciones.

## Estructura del proyecto

- `index.html`: página principal con enlaces a ambos sitios.
- `tecnologias/`: sitio de tecnologías.
- `cafe/`: sitio de café.
- `android/`: recursos del proyecto.
- `LEEME.txt`: notas del proyecto.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (validaciones en archivo independiente)
- Bootstrap (mensajes de validación y diseño responsivo)
- Google Fonts
