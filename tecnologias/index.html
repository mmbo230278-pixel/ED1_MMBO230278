Tecnologías Web

HTML

HTML es el lenguaje que da estructura a una página web. Con él se escriben los títulos, párrafos, imágenes, enlaces y formularios.

CSS3

CSS3 se encarga de la apariencia: colores, tipografías, tamaños y la forma en que se acomodan los elementos en pantalla.

JavaScript

JavaScript le da vida a la página: responde a los clics y revisa que los datos del formulario estén bien antes de enviarlos.

Bootstrap

Bootstrap es un framework con estilos ya hechos. En este sitio lo usamos para mostrar los mensajes de validación del formulario.
